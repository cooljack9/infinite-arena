# v2.6.0 发布说明 · 本地版 — 暴击/爆伤软上限机制

> 承接 v2.5.0（地形像素化 + 动作调参）。本批头牌是 `packages/core` 冻结层的机制改动：暴击封顶 80%、溢出转爆伤、爆伤 320% 后软膝衰减。
> 同步合入此前累积的 app 层视觉/战报修复与渲染折中。

## ⚔️ 暴击/爆伤软上限（core 机制，PRD: docs/v2.6.0-暴击爆伤软上限机制-计划.md）

用户拍板参数：暴击 **80% 软上限**；超出部分 **1 点暴击率 : 1 点爆伤** 转入 `critDmg`；`critDmg` 超过 **320%** 后增量效用只剩 **10%**（软膝，非硬墙）。

- 新增 `applyCritSoftCap(d)`（`packages/core/src/engine/unit.ts`）：作为派生全链路组装完成后的**最终归一化步骤**。
- 三处写入路径全部过软上限，保证英雄 / 敌方 / 场地全局一致：
  - `makeAlly` / `makeEnemy` 建造链（build 期）；
  - 遗物 `applyRelics`（`engine/battle/relics.ts`，战斗开始追加后）；
  - 天气/场地 `applyWeather`（`engine/battle.ts:188`，含虚空侵蚀 +16% 等场地暴击）。
- 溢出保真：把装备/性别/坐骑的 crit 硬上限（90/92）改为 200 护栏，让未截断的原始和流到软上限统一裁决，避免「性别 +5 被 90 截断」之类丢失溢出。
- 与 `lateDecay` 共存：战斗期 `effCritDmg = derived.critDmg + 10*lateDecay()` 的终局追赶临时加成**加在软膝之后**，软膝只压「构筑」溢出，不压「战局追赶」。

> 影响：原本堆到 90%+ 暴击的角色封顶 80%，多余转爆伤（高暴击率下爆伤放大更划算，DPS 更平滑收敛）。预期内平衡变动，已通过确定性门禁复验。
