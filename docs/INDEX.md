## 版本体系（v2.3.0 单一基线）

本仓自 **v2.0.0** 起收敛为**单一版本轴**：`package.json` 的 `version`、`CORE_VERSION`、git tag、压缩包名、线上 Pages，以及全部文档的版本声明，**共用同一个号 `2.4.2`**。

| 旧编号体系 | 旧值 | 现状 |
|---|---|---|
| 本地版线（README / docs） | `v1.9.0` | **作废** → `v2.0.0` |
| 后端交付线（docs/backend） | `v3.1.0` | **作废** → `v2.0.0` |
| 包版本线（package.json） | `4.0.0` | **作废** → `2.0.0` |
| 回放契约线（CORE_VERSION） | `4.2.0-van` | **作废** → `2.0.0`（⚠ 旧 replay / 存档不可复用） |

规则：
1. `CORE_VERSION` 必须**恒等于** `package.json` 的 `version`，二者不一致即为事故。
2. 任何触及 `packages/core/` 的改动一律**整体升号**，不再存在独立的回放契约号。
3. 历史文档文件名中保留的旧版本号（如 `v2.9.13-发布说明.md`）**仅为历史文件名与里程碑代号，不具发布号效力**。

> 历史字节级重复文件已归档至 `docs/archive/` 与 `docs/backend/archive/`（内容一致，仅保留一份用于日常查阅）。
