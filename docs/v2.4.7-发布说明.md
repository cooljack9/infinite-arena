# v2.4.7 发布说明 · 本地版 — 整备界面拆分

> 对应计划：`docs/v2.4.7-本地版-整备界面拆分与像素风改造-计划.md`（批次 1）。

## ✨ 用户体验

- **战后整备界面全面拆分**：旧版把 11 组信息竖向堆在一屏（用户反馈「看一眼就会爆炸」），现改为
  「常驻头部 + 4 个聚焦页 + 常驻底部行动栏」，每页信息组 ≤ 3 个：
  - ⚔ **战报**（战后默认页）：突破/成长摘要（紧凑条）· 成长三选一 · 战利品开箱 · 建议下一步
  - 🛡 **队伍**：英雄卡（面板/出售/星级/装备位）· 一次性药剂
  - 🛒 **补给**：商店货架 · 英雄招募
  - 🎽 **装备**：子页签 穿戴 / 融合
- **建议下一步升级为跳页锚点**：一键装备→装备页·穿戴；一键全买→补给页；可合成→装备页·融合。
- 状态栏（层数/金币/交易折扣/背包/掉落箱/本层合成）与底部行动栏（下一层/下五层/自动爬塔/放弃挑战）常驻，不随页切换。

## 🔒 兼容性

- 全部 `tut-*` 教学锚点原位保留；`TutorialOverlay` 的锚点→页面映射升级为 锚点→{页面,子页签}，
  教学推进时自动切页（含装备子页签）。
- EquipTab / ForgeTab / ShopTab / ClimbConfig / HeroPanel / FilterBar / EqCard 零改动复用。
- 纯 UI 层重组：packages/core 与 sim 数学零触碰，parity 门禁原样通过。
