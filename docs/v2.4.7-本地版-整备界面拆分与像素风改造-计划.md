## 背景诊断

`src/screens/intermission/IntermissionHub.tsx`（683 行）将 **11 组信息** 竖向堆叠在一屏：
标题、状态标签×5、突破横幅、战后成长横幅、成长三选一、战利品开箱、队伍面板/出售、建议下一步、
穿戴/融合/商店三合一 tab、折叠区（药剂+招募）、底部四大行动按钮，外加 4 个弹层。
无页面层级，扫视成本极高 → 「看一眼就爆炸」。

视觉侧：现有 aurora 主题为现代 UI 语言（4~18px 圆角、模糊 glow、缓动曲线），
与战斗画布的像素渲染（最近邻放大、有限色板）不统一。

## 批次 1（v2.4.7）：整备界面拆分 — 信息架构重组

**结构：常驻头尾 + 4 个聚焦页**，每页信息组 ≤ 3 个：

| 页面 | 默认 | 信息组 |
|---|---|---|
| ① 战报 | ✔（战后落点） | 突破/成长摘要（可折叠一行式）· 战利品开箱 · 建议下一步（跳页锚点） |
| ② 队伍 | | 英雄卡（面板/出售/星级/装备位）· 一次性药剂 |
| ③ 补给 | | 商店货架（ShopTab）· 英雄招募 |
| ④ 装备 | | 子页签 穿戴(EquipTab) / 融合(ForgeTab) |

- **常驻头部**：第 N 层 · 金币 · 背包/掉落箱 · 交易折扣（不随页切换）。
- **常驻底部行动栏**：下一层 / 下五层 / 自动爬塔 / 放弃挑战（不随页切换）。
- 突破与战后成长横幅改为**战报页内的紧凑摘要**，不再全局顶置。
- 「建议下一步」保留推荐逻辑，动作改为**跳转到对应页**（一键装备→装备页·穿戴；一键全买→补给；可合成→装备页·融合）。

### 硬约束

1. **教学锚点全数保留**：所有 `tut-*` DOM id 不变；`TutorialOverlay onStep` 的锚点→页面映射升级为

3. **纯 UI 层**：不触碰 packages/core 与 sim 数学，parity 门禁必须原样通过。
4. 状态归属下沉：opening（开箱）归战报页；useTarget（药剂）/sellConfirm 归队伍页；
   recruitRefreshing/recruiting 归补给页；HeroPanel 的 panel 状态留中枢（两页共用）。

## 批次 2（v2.4.8）：全站像素风 — 设计令牌换皮

> 待批次 1 验证后实施。方向已与用户对齐：**字体保持系统栈不像素化**（用户拍板 2026-09-25：战斗画布内普通字体无违和感，无需 1.8MB 像素字体拖累首屏），仅做风格像素化。

- `:root` 令牌层一次性改造（组件零改动，CSS 已注释保证）：
  - `--r-*` 圆角全部归零（像素方块，含 --r-pill）。
  - 阴影去模糊：改硬偏移阶梯阴影（`Npx Npx 0` 式）；去 glow（改 `0 0 0 2px` 硬描边）。
  - 面板/按钮像素 bevel：inset 亮暗双条模拟凸起。
  - 动效改 `steps()` 帧步进（--ease/--ease-out + 关键呼吸动画），与战斗逐帧动画同语言。
  - 全屏背景：aurora 模糊辉光层 → 像素扫描线（repeating 条纹，无 blur 无动画，保留低质量档兼容）。
  - 位图 `image-rendering: pixelated`。
  - 色板保持 aurora 暗色调（低饱和紫底金accent 与战斗色板兼容）。
- 范围：index.css 令牌与组件类 + 全屏背景；不改各屏 JSX 结构。
- 工具：node 确定性正则脚本批量硬化剩余散落的模糊阴影/辉光，替换后 grep 复核清零；改前备份 `_index.css.v247.bak`（仓库外）。
