# 无限勇者竞技场 v3.1.0 发布说明

> ⚠ **版本体系已统一**：本仓自 **v2.0.0** 起收敛为**单一版本基线** —— `package.json`、`CORE_VERSION`、git tag、压缩包、线上 Pages、全部文档共用唯一版本号 `2.0.0`。本文标题与正文中出现的其它 `vX.Y.Z` 均为**历史里程碑代号**，不再具有发布号效力（详见 `docs/INDEX.md`「版本体系」）。

> 版本定位：**六项用户反馈修复**。三项是数值/机制的真 bug（必爆判定、升星不生效、生成物撞号），三项是可读性与个体差异的补齐（个体姓名、部署页可视化、性格索敌）。
>
> 版本号说明：代码注释中的 `v3.0` 指 v2.9.13/v2.9.14 里程碑，`v3.1` 即本版；package.json 由 `2.9.14` 直升 `3.1.0` 与注释对齐。

## 一、贯日神射：修「伤害翻倍」为「必定暴击」

- **问题**：`deadshot` 对生命 >50% 的目标同时给了 **×2 伤害** 与 **强制暴击**，实际结算是 `400% × 2 × 暴伤`。而技能描述与二段说明都只写了「必暴」——数值与文案长期对不上，玩家读到的「必爆」和实际打出的「翻倍」是两回事。
- **修复**：伤害恒为 **400% 物伤**（再乘星级乘子），高血量目标只吃「必定暴击」这一条布尔量。血线抽为常量 `STAGE2_CFG.deadshotCritHpGate = 0.50`，消除原先「满血必暴」与「>50% 翻倍」两条门槛并存的混乱。
- 文案同步：技能描述改为「9 格内单体 400%物伤，蓄力贯日一击」，二段改为「目标生命高于 50% 时，本次射击必定暴击（伤害倍率不变）」。

## 二、升星真正强化签名技（不再「开局就满级」）

| 项 | 公式 | 5★ 实际值 |
|---|---|---|
| 技能等级 | `skillLevelOf(star) = clamp(1,5,round(star))` | 5 |
| 效果乘子 | `skillPowerMult = 1 + 0.18 × (level − 1)` | **×1.72** |
| 冷却缩减 | `skillStarCdr = 0.04 × (level − 1)` | **−16%** |

- 乘子作用于签名技的**伤害 / 护盾 / 治疗 / 召唤物攻与血**，不作用于普攻与坐骑技（坐骑另有品质乘子，叠在一起会变成无法平衡的双重指数）。
- 星级 CDR 与专属红装 CDR **先相加再统一封顶 55%**——分别封顶会让「5★ 角色 + 5★ 专属红装」拿到 45%+16%=61%，大招循环快到能盖住整局节奏。
- 召唤物**攻击与生命同乘**：只抬攻击的话，召唤流升到 5★ 依旧是一群一碰就碎的纸人，玩家读不到升星收益。

## 三、场内生成物编号唯一

- **问题**：召唤物 id = `'sum' + Math.floor(time*1000) + kind`、Boss 分身 id = `clone{time*1000}_{idx}`。同一 tick 内两名召唤师同时出同类型召唤物（或「军团」特性一次补两只）会拿到**完全相同的 id**。id 是 `targetId` / `damagers` / `pathCache` / 渲染 key 的主键，撞号会引发索敌串目标、寻路缓存互相污染、渲染插值跳变等一连串隐性 bug。
- **修复**：`BattleSim` 实例级单调计数器 `spawnSeq` + `nextSpawnId(prefix)`，召唤物与分身共用一条序列。挂在 sim 实例而非模块级——同 seed 同回放必然同序列，又不会被「玩家开过几次编队界面」这类外部调用次数污染。

## 四、每个角色一个随机姓名

- 旧显示名是「职业称号 + 罗马数字」（`铁壁镇守 II / III`），在部署页、战报、装备列表里到处出现，把三个属性/体型/性别都不同的角色写成了同一个人的三份拷贝。
- 新增 `content/names.ts`：姓取百家姓，名按性别分池取字、1~2 字随机，**完全由种子驱动**（同 seed 同名，不破坏确定性回放），支持传入「已占用姓名」做同队去重。
- `HeroDef.personalName` 承载姓名，`Unit.title` 承载职业称号，两者在面板上成对展示；`displayName` 不再追加任何后缀。开局三人与后续招募均逐个累积去重。

## 五、部署页：危险地形 + 职业剪影棋子

- **地形可见**：补齐 **岩浆 `M`** 与 **深水/虚空 `~`** 的瓦片渲染（配色与战斗画面 `frame.ts::drawTile` 同源，楚河汉界=水蓝 / 八角笼=岩浆红 / 默认虚空黑），并加**按需图例**（扫 tilemap 决定显示掩体 / 岩浆 / 深水 / Boss 台）与逐格提示（如「岩浆：可通行，每秒灼烧 3% 最大生命」）。玩家是在这张图上决定站位的，战斗时才发现脚下是岩浆等于布阵信息不完整。
- **棋子重做**：由「纯色圆 + 1 个字」改为**职业专属像素剪影 + 底部姓名条**——复用战斗同源的 `drawSprite`，含体型 / 性别 / 星级，与实战外观一致；底色为职业色低透明、边框为职业色。格宽 `CELL` 22 → **26**（22px 塞不下可读姓名，26px 是「名字看得清」与「20 列不炸屏」的折中）。
- 悬停 tooltip 扩展为「姓名（职业中文名） · 性格：一行短说明」。

## 六、性格系统（体型之外的第二条个体差异线）

| 性格 | 索敌偏好 |
|---|---|
| 不畏强暴 | 优先攻击生命 > 80% 的敌人 |
| 猎手 | 优先攻击当前生命百分比最低者 |
| 攻坚者 | 优先攻击敌方前排 |
| 专业刺客 | 优先攻击敌方后排 |
| 救困扶危 | 优先攻击战力评分最高者 |
| 随遇而安 | 就近选择（= v3.0 默认行为，权重 1.6） |

- **只影响索敌，不给任何数值加成**。它是风味与战术变量，不是第三条养成线——否则玩家会去刷性格，而不是玩阵容。
- **不做纯优先级，做「偏好分 × 6 − 距离」的加权**。纯优先级会让近战刺客无视贴脸坦克、横穿整张图去够后排法师，路上被围殴致死——玩家看到的不是「性格」，是「AI 犯蠢」。6 格的距离预算把偏好换算成「我愿意为这个目标多走几步」。
- **前排/后排以我方阵型重心为基准**（排除召唤物），而不是攻击者自身位置——用自身位置的话「前排」会退化成「离我最近」，攻坚者与随遇而安就没区别了。
- **嘲讽优先级高于性格**：控制效果必须能压过个性，否则前排的存在意义被削掉一半。
- 性格在 `variateHero` 里**属性摇完之后**才取随机数，保证「旧存档 + 同 seed」的 `basePrimary / bodyType / gender` 与 v3.0 逐位一致。

## 七、测试方式升级：从「关键字匹配」到「受控探针」

此前的 smoke 断言大多是在战斗日志里找关键字——这只能证明代码路径被走到，**不能证明算出来的数是对的**，第一项 bug 正是这样被掩盖了一整个版本。

本版新增 `smoke.ts` 的 `[5] v3.1 六项修复` 组，改用**受控探针**：冻结暴击率、把普攻 CD 设为 `1e9`、木桩伤害缩放置 0，只读**第一条数字飘字**，用比值验证机制。

- ① 贯日神射：满血 501 / 45% 血 256 = **1.957 ≈ 暴伤系数 1.955**（若仍翻倍则应约 3.9）。
- ② 升星：先算属性增益 `2.312`，再从总比 `3.980` 中除出**技能增益 `1.722` = skillPowerMult(5)**，把「属性成长」与「技能强化」解耦度量。
- ③ 生成物：3 召唤师 × 8 seed 跑满层，逐 tick 断言 id 集合无重复——32 个生成物、**0 次撞号**。
- ④ 姓名：12 个副本全部有名、无罗马数字/数字后缀、互不重复、同 seed 可复现、预置姓名不被覆盖。
- ⑤ 性格：5 组受控场景（满血中距 / 残血中距 / 敌前排 / 敌后排 / 远处 Boss 诱饵）验证 5 种性格各选中预期目标，5 个 `steady` 对照组全部选最近；3000 次抽取验证 6 种性格全部出现。
