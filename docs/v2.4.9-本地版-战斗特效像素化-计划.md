# v2.4.9 本地版 · 战斗特效像素化（计划）

> 目标：把战斗内特效（技能 VFX + 普攻挥击）从「平滑矢量图元」升级为「具象像素造型」，与单位精灵、UI 令牌层三处语言统一。
> 版本：2.4.8 → **2.4.9**

## 一、根因诊断

单位精灵（`src/render/sprites.ts`）已是成熟像素管线：20×20 模板 + 材质分层 + **离屏 1:1 光栅化缓存 + nearest 放大** + 像素级 bloom。
而技能特效（`frame.ts` `drawEffect`，L1838-2277）仍是**另一套语言**，导致并置时特效显得糊、飘、廉价：

| # | 问题 | 具体表现 |
|---|------|----------|
| 1 | 语言不一致 | 单位是 nearest 锐利像素；特效是 `ctx.arc()/stroke()` 抗锯齿 + `lighter` 连续发光 |
| 2 | 无具象造型 | nova=9 条放射线、ring=圆、beam=直线、quake=8 条折线——没有火焰舌/闪电折角/晶体棱面/符文 |
| 3 | 未对齐像素网格 | 坐标与半径连续变化 → 亚像素抖动（`sprites.ts` 注释已指明这是像素游戏"脏"的主因） |
| 4 | 无逐帧动画 | 进度 `p` 连续插值 = 平滑补间，非像素的帧步进 |
| 5 | 单色无阶 | 直接用 `e.color` + 白高光，缺 暗→中→亮→白热 四阶色阶（材质感来源） |

## 二、方案总览

新增渲染模块，**复用 `sprites.ts` 已验证的同一套纪律**（不另起炉灶）：

```
像素母题网格 → 离屏 1:1 光栅化缓存 → nearest 整数倍放大 → 像素网格对齐 → 逐帧步进
```

**关键工程决策：手绘母题 + 程序化动画。**
不手绘 36 帧（12 shape × 3 帧）——工作量大且难维护。改为：

- 手绘 **20 个 16×16 母题**（12 shape + 8 挥击）作为造型本体；
- 动画由**确定性程序合成**：
  - **整数块缩放**：像素块 1→2→3 px 阶梯放大（扩散感，保住像素格子不变形）；
  - **有序抖动溶解（dither dissolve）**：按 4×4 Bayer 阈值逐格剔除，像素美术经典消散技法；
  - **色阶迁移**：暗→中→亮→白热随进度迁移，模拟能量衰减。

优点：数据量降至 1/3、完全确定性（零 `Math.random`）、风格统一、易调参。

| `bubble` | 护盾泡：圆润护罩 + 高光弧 + 符文块（保留 `shield_pulse` 8 符块语义） |
| `nova` | 爆裂星：中心白热核 + 4 主火舌 + 4 副火舌 + 飞散碎块 |
| `blade` | 刀光：弧形刃口 + 刃线高光 + 尾迹渐隐 |
| `sun` | 曜日：日面 + 8 道星芒 + 日冕碎点 |

### 3.2 新文件

- **`src/render/pixelVfxTemplates.ts`** — 母题网格数据（对标 `sprite-templates.ts`）
- **`src/render/pixelVfx.ts`** — 色阶派生 / 光栅化缓存 / 绘制器 / beam-trail 平铺 / 抖动溶解

### 3.3 渲染器要点

| 项 | 做法 |
|----|------|
| 色阶派生 | 由 `e.color` 用 `shade()` 派生 暗/中/亮/白热 四阶（保留职业识别度） |
| 光栅化缓存 | `Map<'shape\|color\|frame', canvas>`，16×16 **只画一次**，每帧仅一次 `drawImage` |
| 放大 | `imageSmoothingEnabled=false` + **整数倍**缩放，禁用非整数倍拉伸 |
| 像素对齐 | 圆心/端点坐标 `Math.round` 到像素格，半径取整到块尺寸倍数 |
| 动画 | 进度 `p` 量化为离散帧；消散用 4×4 Bayer 有序抖动剔除 |
| 发光 | 像素级 bloom（亮索引向外溢出一圈），**禁用** `shadowBlur` / 大面积 `lighter` 渐变 |
| beam/trail | 沿方向**平铺重复像素段**（格子不变形）+ 命中端挂端点爆点精灵；`long` 档保留十字准星语义 |

## 四、硬约束

1. **core 冻结**：`packages/core` 零改动，`VfxShape` / `Effect` 类型不动，只在渲染侧映射。
2. **确定性**：零 `Math.random`；抖动阈值表、碎块位置全部静态或种子派生（与 `makeParticles` 同族 LCG）。
3. **性能预算**：离屏缓存后每特效每帧 1 次 `drawImage`（现状是数十次 `stroke/fillRect` + 合成态切换），
   严格更高效；沿用现有 `vfxBudget`（`VFX_BUDGET / vfxLoad`）压制同屏 additive 负荷。
4. **五门禁**：tsc / build / guard / parity / smoke 必须全绿。

## 五、验收标准

- 战斗内**看不出**平滑抗锯齿边缘（放大后边缘为硬像素格子）。
- 12 种技能 + 8 种挥击均有可辨识造型，不再是"圆/线"。
- 特效与单位精灵放大后像素块尺寸协调（不出现"单位是 4px 块、特效是连续渐变"）。
- 60fps 下同屏多特效不掉帧（缓存命中，绘制调用数显著下降）。
- 五门禁全绿，确定性不破。
