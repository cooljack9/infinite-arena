# 《无限勇者竞技场》· 全类型用户深度测试调研报告

> **调研对象**：`infinite-arena` v2.0.0（本地版 · 双通路架构 · 三人起队七人满编无尽竞技场）
> **调研角色**：UX Researcher（用户研究专家）
> **调研日期**：2026-08-12
> **调研性质**：混合方法（专家启发式评估 + 用户分层建模 + 可用性测试方案 + 行为数据再诠释）
> **证据来源**：① 仓库源码静态走查（`src/screens/*`、`src/game/*`、`packages/core/*`）；② 既有 v2.9.12 大规模模拟封测报告（10,080 场真实引擎战斗）；③ 架构/发布/设计文档。

---

## 0. 摘要（Executive Summary）

工程质量**扎实**、玩法系统**纵深足够**，但**用户引导与难度体验存在结构性缺口**，会按用户类型产生"分层流失"。

| 维度 | 结论 | 判定 |
|---|---|---|
| 新手引导覆盖 | 教学浮层**仅 novice 模式**存在；无尽/铁人**零引导** | 🔴 P0 |
| 首玩留存体验 | 难度曲线每 5 层一堵"titan 墙"，中位玩家裸装平均推进 **4.86 层** | 🔴 P0 |
| 休整屏认知负荷 | 单屏聚合 8 类操作，移动端信息过载 | 🟠 P1 |
| 高阶机制可读性 | 突变/真空/突破/遗物/三选一/下五层/自动爬塔均无解释 | 🟠 P1 |
| 无障碍 | 色盲双通道已做；但缺图鉴、缺高代价操作二次确认 | 🟠 P1 |
| 内容可见性 | 6 个特性零触发（含「大招」），硬核期待落空 | 🟠 P1 待确认 |
| 系统一致性 | 主菜单/休整/PreBattle 三处交互范式不统一 | 🟡 P2 |

**一句话**：游戏对"硬核优化者"和"铁人赌徒"是优秀产品；对"萌新/休闲移动/回流老手"则在第 5~11 层出现**引导缺失 + 难度断崖**的双重劝退。**全类型用户调研的核心命题，是让每种用户在各自的熟练度区间内都能获得"可理解的进步感"。**

## 1. 调研背景与目标

### 1.1 产品定位（来自代码与文档）
- 玩法：角斗士公会经理 × Roguelike 无尽（参考挑战杯模式）。三人起队，至多扩至七人满编。
- 模式：新手（5 层教学战役）/ 普通无尽（至 500 层）/ 铁人无尽（阵亡永久消失）。
- 核心循环：`编队 → 战前布阵+三选一 → 自动战斗(可手动技能) → 休整(开箱/装备/锻造/商店/招募) → 下一层`。
- 技术：Local/Remote 双通路，Pure Core 纯函数权威结算（确定性、可离线、可上云）。

### 1.2 调研目标
1. **识别全类型用户**：把"所有可能玩家"切分为可研究、可测试、可服务的用户分群。
2. **评估当前 UX 对各类型的友好度**：用 Nielsen 10 项启发式 + 走查证据逐项评估。
3. **量化体验分层**：用既有平衡数据重诠释"不同类型用户会卡在哪一层"。
4. **产出可执行方案**：每个发现配优先级、改法、成功指标。

### 1.3 关键口径（重要）
- 既有封测为**裸装基线**（无装备/天赋/坐骑/养成），绝对胜率偏低；**相对对比有效**。
- 本报告用其做"体验分层"推演，结论指向的是**系统骨架的友好度**，而非真实玩家绝对值。

## 2. 调研方法论（Research Methodology）

### 2.1 混合方法设计

| 方法 | 用途 | 样本/口径 | 在本报告中的角色 |

| **用户分层建模** | 定义全类型用户与画像 | 5 维度 × 8 画像 | 第 3 节 |
| **用户旅程地图** | 定位各类型痛点时刻 | 3 条代表旅程 | 第 4 节 |
| **行为数据再诠释** | 量化"卡层"与流失风险 | 源自 10,080 场封测 | 第 7 节 |
| **可用性测试方案** | 给出可执行的测试 Protocol | 含任务/指标 | 第 5 节 |

### 2.2 建议的上线前可用性测试配置
- **定性**：每类型 5 人（8 类型共 40 人）， moderated 远程 + 出声思考（think-aloud），每场 45 分钟。
- **定量**：每类型 ≥ 30 人（共 ≥ 240）的无 moderated 任务完成率 + SUS 量表 + 单层流失遥测。
- **招募**：覆盖 iOS/Android/Web；含色盲（≥4 人）、左手操作（≥3 人）、40 岁以上（≥8 人）。

### 2.3 需新增的遥测事件（用于"深度测试"闭环）

```
battle_start(layer) → battle_end(layer, result, failures)

```

## 3. 全类型用户分层与画像（User Taxonomy）

按 **5 个正交维度** 切分，覆盖"全类型用户"：熟练度 × 模式 × 操作方式 × 平台 × 无障碍。最终收敛为 **8 个差异化画像**（每个画像跨多个维度）。

| # | 画像 | 熟练度 | 主模式 | 操作 | 平台 | 核心诉求 |
|---|---|---|---|---|---|---|
| P1 | 萌新小白 | 极低 | 新手 | 被动教学 | Web/移动 | 看懂规则 |
| P2 | 通勤碎片 | 低 | 无尽 | 自动+建议 | **安卓** | 轻松爽 |
| P3 | 花样收集 | 中 | 无尽/铁人 | 半自动 | 双端 | 集齐养满 |
| P4 | 数据狂魔 | 高 | 无尽 | 手动+精算 | 桌面 | 冲最高层 |
| P5 | 亡命赌徒 | 高 | **铁人** | 手动 | 桌面 | 无死亡登顶 |
| P6 | 托管挂机 | 中 | 无尽 | **全自动** | 移动 | 效率收菜 |
| P7 | 色盲战友 | 跨 | 跨 | 跨 | 双端 | 平等体验 |
| P8 | 回流老手 | 中 | 无尽 | 半自动 | 双端 | 快速找回手感 |

### 3.1 详细画像卡

#### P1 萌新小白（Novice Onboardee）
- **人口**：首次接触；被"三人小队"题材与美术吸引。
- **目标**：在 5 层教学里理解"编队→布阵→开战→开箱→下一层"。
- **痛点**：① 教学浮层仅在 novice 出现，**通关后切无尽立刻"裸奔"**；② 第 5 层冲刺教学后无"接下来去哪"的引导；③ "建议下一步"在休整屏才出现，PreBattle 无任何引导。
- **成功标准**：新手模式完成率 ≥ 90%，且 70% 新手愿意"继续无尽"。

#### P2 通勤碎片（Casual Mobile）
- **人口**：安卓用户，地铁/午休碎片时间，单局 3–8 分钟。
- **目标**：自动战斗 + "建议下一步" + 自动爬塔，低思考爽玩。
- **痛点**：① 休整屏信息密度极高，小屏需大量滚动；② "下五层/自动爬塔"的代价（敌×1.20、扣容错）看不懂；③ 无"一键最优"会卡在"该买什么/该穿什么"。
- **成功标准**：移动端单次休整操作 ≤ 6 次点击到达下一层；自动爬塔使用率 ≥ 40%。

#### P3 花样收集（Completionist / Whale）
- **人口**：追求满编 7 人、全英雄招募、升星 5★、突破、幻化。
- **目标**：集齐内容、养满数值。
- **痛点**：① 无 in-game 图鉴（英雄/装备/特性/遗物）无法追踪收集进度；② 招募/升星的经济节奏不明；③ 召唤师统治导致"不抄作业就养歪"。
- **成功标准**：图鉴完成度成为留存抓手；满编 7 人达成率可观测。

#### P4 数据狂魔（Hardcore Optimizer）
- **人口**：研究 meta、配装、遗物组合、布阵坐标；看社区攻略。
- **目标**：冲最高层、验证 build。
- **痛点**：① 6 个特性零触发（含「大招」），期待落空；② 召唤师统治使策略空间坍缩到 ~8 套；③ 无"本局最优解提示"，依赖外部；④ 缺乏深层数据回放/战斗日志导出。
- **成功标准**：高层（≥L30）达成人数；build 多样性指数。

#### P5 亡命赌徒（Ironman Permadeath）
- **人口**：高风险偏好，享受永久代价。
- **目标**：无死亡登顶。
- **痛点**：① **铁人阵亡永久消失，但 PreBattle 无"本层若败将永久失去 X"强提醒**（高代价操作缺二次确认）；② 失败扣容错规则分散在 tooltip；③ 误触"下五层"扣 2 次容错。
- **成功标准**：铁人模式首局平均存活层；误触率下降。

#### P6 托管挂机（Auto-delegator）
- **人口**：用自动爬塔 + 倍速，把游戏当收菜。
- **目标**：效率推进、挂机收益。
- **痛点**：① 自动爬塔要求 `failures<2` 才可用，前两次失败即锁；② 爬塔"本层后停止"需手动点，无"到某层自动停"；③ 倍速上限 4×，长局仍慢。
- **成功标准**：自动爬塔单次连清层数；托管满意度。

#### P7 色盲战友（Accessibility）
- **人口**：红绿色盲等视觉差异用户。
- **目标**：平等体验战局。
- **痛点**：① 色盲双通道**已做**（▲我方/▼敌方 + 蓝橙血条），是亮点；② 但战利品图标（🔵🟣💎）、稀有度配色、Boss 红字仍主要靠色；③ 无字体/对比度/动效降级选项。
- **成功标准**：色盲用户任务完成率 ≈ 普通用户（差异 < 5pp）。

#### P8 回流老手（Returning Mid-core）
- **人口**：玩过旧版，懂基础但模式多已忘。
- **目标**：快速找回手感，不被新系统劝退。
- **痛点**：① 无尽/铁人无教学，回流即裸奔；② 突变/真空/突破/遗物等新机制无"这是什么"入口；③ 旧肌肉记忆（跳过本层）已移除，无说明。
- **成功标准**：回流 7 日留存；首局到达层 ≥ 旧版记忆层。

## 4. 用户旅程地图（Journey Maps）

以"核心循环"为主线，标注三类代表用户的情绪与痛点。

```
阶段:  主菜单 ──▶ 编队 ──▶ 战前 ──▶ 战斗 ──▶ 休整 ──▶ (循环) ──▶ 深层瓶颈
情绪:  好奇      期待    谨慎   紧张   满足    满足      挫折/劝退
       │         │       │      │      │       │        │
P1 萌新 ▼教学✅   ❓锁3人  ❓布阵  ❓技能  ✅建议✅ ❓下一层 ❌无引导+第5层墙
P2 休闲 ▼选模式   ⚠随机    ⚠看不懂 ⚠自动  ⚠信息过载 ⚠该买啥  ❌看不懂代价+断崖
P4 硬核 ▼无尽🔓   ✅预设    ✅布阵  ✅手动  ⚠无图鉴  ✅全开    ⚠大招/击退0触发+召唤师墙
```

### 4.1 关键痛点时刻（Pain Moments）
- **PM-1 模式切换裸奔**：novice 通关 → 无尽，教学消失（P1/P8 重灾）。
- **PM-2 第 5 层断崖**：titan 层胜率从 ~70% 跌到 31%（裸装），劝退墙（全部非硬核）。
- **PM-3 休整认知过载**：单屏 8 类操作，移动端滚动成本（P2/P6）。
- **PM-4 高代价无确认**：铁人永久消失、下五层扣 2 容错无强提醒（P5）。
- **PM-5 内容不可见**：6 特性零触发、无图鉴（P3/P4）。

## 5. 可用性测试方案（Usability Test Protocol）

### 5.1 通用结构（45 分钟 / 人）
1. 暖场与背景（5'）
2. 出声思考首玩（20'）：从主菜单到打完第 3 层
3. 定向任务（12'）：按画像给任务（见下）
4. 访谈与 SUS（8'）

### 5.2 分画像任务卡（节选）

| 画像 | 任务 | 成功指标 | 观察重点 |
|---|---|---|---|
| P1 | 完成新手 5 层，再尝试进入无尽 | 完成率、是否困惑"接下来" | 教学断点、下一层引导 |
| P2 | 安卓上用"建议下一步"打完 3 层 | 休整点击 ≤ 6 次/层 | 信息密度、滚动、误触 |
| P3 | 招募 1 名新英雄并升星 | 是否理解经济/养成 | 图鉴缺失影响 |
| P4 | 手动施放技能 + 三选一 + 布阵打 L10 | 是否理解机制、是否找最优 | 特性触发、meta 提示 |
| P5 | 铁人模式打到第 3 次失败 | 阵亡前是否意识到永久代价 | 高代价确认缺口 |
| P6 | 用自动爬塔连清若干层 | 是否理解策略/胜率阈值 | 爬塔可用性、停止点 |
| P7 | 开启色盲模式完成 1 战 | 敌我辨识准确率 | 双通道是否够、稀有度配色 |
| P8 | 回流直接进无尽打 5 层 | 是否找回手感、新机制困惑 | 教学缺口、术语 |

### 5.3 量化指标
- **任务完成率（TCR）**、**单次休整操作步数**、**首玩到达层**、**SUS ≥ 68（达标）**、**NPS**、**第 5 层流失率**、**7 日留存**。

## 7. 体验分层（用平衡数据重诠释"卡层"）

将封测逐层胜率（裸装基线，84 阵容均值）按用户类型重映射，展示**不同类型用户会卡在哪一层**：

| 用户类型 | 代表阵容强度 | 首道墙 | 中位到达层(裸装推演) | 流失风险 |
|---|---|---|---|---|
| P1 萌新（误选/随机） | 中位偏下 | L5（31%） | ~3–5 | 🔴 极高 |
| P2 休闲（靠建议） | 中位 | L5→L11 断崖 | ~5–7 | 🔴 高 |
| P4 硬核（最优阵） | Top 阵容 | L11（16.7%） | ~11–15 | 🟠 中 |
| P5 铁人（最优+谨慎） | Top | L11 + 永久代价 | 更深但容错吃紧 | 🟠 中 |
| P3/P6/P7/P8 | 中位 | L5–L11 | ~5–11 | 🟠 中高 |

> **关键洞察**：即便最优化阵容，裸装也在 **L11 遭遇 16.7% 断崖**；休闲/误选阵容在 **L5 即 31% 劝退**。难度曲线是**全类型共享的流失主因**，须与"引导缺失"同步修。

（封测绝对胜率偏低，真实玩家因装备/养成更深；但**断崖形状与相对位置不变**，故卡层区间可信。）
