# 编队英雄卡描述需求（待实施）

## 背景
用户反馈：线上 TeamBuilder 选人界面，英雄卡 `玄武前排·` 之后描述为空（「线上未载入描述」）。

## 根因（非 bug，设计预期）
- `src/screens/TeamBuilder.tsx:73` 显示 `{info.cn} · {h.trait}`。
- `packages/core/src/content/heroes.ts:35-39`：模板定义时 `trait: undefined`；身材特性（trait）由 `packages/core/src/content/variant.ts:80` 的 `variateHero()` 在**出征时**从全池随机生成（选人阶段刻意不泄漏随机信息）。
- 1.9.0（36ce3a4）未改 TeamBuilder.tsx（git log 确认）；`SUBCLASS_INFO`（classes.ts:16-26）无 `desc` 字段。

## 需求（用户拍板）
英雄卡显示：**基本职业特征 + 近战/远程**。

- 基本职业特征 = `SUBCLASS_INFO[h.subclass].defaultBody` → `BODY_INFO[defaultBody].trait`（悬停 title 显示完整 traitDesc）。
- 近战/远程 = `rangeLabelOf(attackRange)`：射程 ≤3.0 近战（tank 1.1 / charge 2.5 / hexblade 3.0）；>3.0 远程（gunner 5.0 / sniper 6.5 / controller 6.0 / summoner 5.0 / healer 5.0）。
- 显示形如：`玄武前排 · 压迫 · 近战`。

## 实施要点
1. `packages/core/src/content/classes.ts`：在 `ALL_SUBCLASSES` 之后加
   ```ts
   export const MELEE_MAX_RANGE = 3.0;
   export type RangeLabel = '近战' | '远程';
   export const rangeLabelOf = (range: number): RangeLabel => (range <= MELEE_MAX_RANGE ? '近战' : '远程');
   ```
2. `src/screens/TeamBuilder.tsx`：import `BODY_INFO, rangeLabelOf`；第 73 行改
   ```tsx
   <div
     className="hero-cat"
     title={`${BODY_INFO[info.defaultBody].trait}：${BODY_INFO[info.defaultBody].traitDesc}（出征后身材随机）`}
   >
     {info.cn} · {BODY_INFO[info.defaultBody].trait} · {rangeLabelOf(info.attackRange)}
   </div>
   ```
3. `npm run typecheck` 通过（已实现验证，后按「先记录需求」要求回滚）。
