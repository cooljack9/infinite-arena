# 无限勇者竞技场 v2.9.14 发布说明

> 版本定位：手感与演出大版本。两项核心改动均为「确定性零影响」——播放速度只改渲染回放、终局衰减是 sim.time 的纯函数，同 seed 回放逐字节一致。

## 一、层内动态播放速度曲线（演示预热 → 正常 → 渐进加速）

每层（一局战斗）按游戏内经过秒数自动调节**回放速度**，与玩家手动倍速相乘：

| 层内经过 | 回放速度 | 说明 |
|---|---|---|
| 0–10s | 0.6× | 演示预热：慢放让开局站位/技能起手看得清 |
| 10–20s | 1.0× | 正常速度 |
| 20s 起 | 每 5s +20% | 渐进加速，封顶 3.0× |

- 仅作用于渲染层 `acc` 累加系数，**不影响 `sim.time` 与战斗结果**（确定性零影响）。
- 与玩家手动倍速叠加：默认 1× 时即纯曲线；玩家拉到 4× 时曲线仍叠加其上。
- 实现：`src/game/state/slices/helpers.ts` 的 `layerTimeScale(t)` + `src/render/ArenaCanvas.tsx` 渲染循环。

## 二、30s 后终局衰减（物/魔减伤↓、爆伤↑）

层内经过 **30s 后**，所有单位（友方与敌方同受）的属性随时间线性变化：

- 物理减伤 / 魔法减伤：**每秒 −2 个百分点**（pp），下限 0；
- 暴击伤害：**每秒 +10 个百分点**（pp）。

- 基于 `sim.time` 的纯函数（`effResist` / `effCritDmg`），**确定性零影响**，按游戏秒计（与回放速度无关）。
- 30s 前属性完全正常；30s 后战局进入「终局」阶段，越拖越脆、越拖越爆——逼玩家在窗口内决战。
- 实现：`src/game/engine/battle.ts` 的 `lateDecay` / `effResist` / `effCritDmg`，接入 `applyDamage`、`basicAttack`、`dealSkill`。

## 三、音效系统大升级（重击 / 轻击 / 大招 × 英雄 × 性别）

- 新增**重击音** `hit_heavy`：比轻击更厚重的低频撞击 + 子类签名音。
- **轻击 / 暴击 / 大招** 全部随「英雄（子类）× 性别」分化音色：
  - 性别：男低频沉、女高频亮（基频与噪声亮度不同）；
  - 子类：9 英雄各有**签名根频**，大招起手后叠一个可辨识的签名音，闭眼也能分清是谁在放招。
- `AudioCue` 新增 `variant { subclass, gender }` 字段；渲染层 `deriveTimbre` 据此派生音色，仿真零影响。
- 实现：`src/types.ts`、`src/audio/AudioEngine.ts`、`src/audio/sfx.ts`，触发点在 `battle.ts` 的命中 / 重击 / 施法 emit。
