# 《无限勇者竞技场》破局方案 · 英雄人格化

> 定位校准：核心体验 = **经营一支角斗士队伍**（经理模拟驱动）
> 破局杠杆 = **英雄人格化**：角色有意志 + 成长节奏不同 + 经营压力落到人身上
> 日期：2026-09-10（v2 修订，并入成长原型 / 成长自我选择 / 工资系统）｜ 2026-09-12（v2.2 新增 2.5 风格化体系） ｜ 状态：待评审

---

## 0. 一句话结论

游戏不缺系统深度，缺的是**玩家对角斗士的情感投资**。当前角斗士是"可替换的数值模块"：招募=抽数值、升星=加数值、突破=加数值，于是所有经营决策退化为纯数值优化。

人格化的目标不是加叙事皮，而是三件事：
1. **角色有意志** — 他想成为什么，你只能引导，不能全权捏
2. **成长节奏不同** — 团队不同步变强，前期拖后腿的后期可能反超（数码宝贝：太一 / 光子郎 / 阿和）
3. **经营压力落到人身上** — 养不起就得裁，**裁员是你亲手决定的**，比阵亡更纠结

---

## 1. 问题诊断（Why）

### 1.1 已具备的（不用推翻）
- 资源运筹层完备：招募、养成、装备词条、锻造重铸、合成升星、商店经济、折扣机制
- 战斗：自动战斗 + 手动技能，Pure Core 确定性结算，本地/云端双通路
- 内容结构：三人起队、七人满编、无尽层、Boss 每 10 层、铁人模式永久阵亡

### 1.2 真正的缺口
| 现象 | 根因 |
|---|---|
| 深度有质量，玩家感知不到 | 复杂在**后台**（词条/概率），**前台决策贫乏**。玩家能感知的深度才算深度 |
| 兴趣起不来 | 兴趣 ≈ 情绪波动 × 主控感。自动战斗削弱主控感，数值增长不产生戏剧性 |
| "没表达出一开始的想法" | 想做的是"经营一支队伍"，做成了"优化一支数值队伍"——**人不见了** |
| 6 个特性零触发（含大招） | 后台复杂度无法转化为前台体验（调研报告佐证） |

### 1.3 核心判断
**继续加系统只会让后台更重、前台更空。** 破局点是让"人"和"抉择"回到中心。

## 2. 三个核心机制（新增，方案主体）

### 2.1 成长原型（Growth Archetype）· 差异化节奏

参考数码宝贝第一部：太一（神化核心）、光子郎（技术偏科）、阿和（慢热、前期像拖后腿、后期起来）。

| 原型 | 类比 | 初始战力 | 每层成长 | 上限 | 薪资水平 | 经营含义 |
|---|---|---|---|---|---|---|
| **早熟型** Prodigy | 太一 | 高（×1.25） | 低（×0.75） | 中（×0.9） | **高** | 开局 carry，后期被追上，性价比递减 |
| **专精型** Specialist | 光子郎 | 主维 ×1.4，其余 ×0.85 | 集中主维 | 单维极高 | 中 | 需围绕他配装配队，策略核心 |
| **晚成型** Late Bloomer | 阿和 | 低（×0.8） | 高（×1.4） | 高（×1.15） | **低** | 前期拖后腿，L35+ 反超，情感回报最大 |

> 数值为设计示意，需封测调平；反超点目标区间 **L35–L40**。
> 可选第四种「均衡型 Steady」作为保底（无亮点但稳），建议 v1 先做 3 种。
>
> ⚠ **原型给的是「期望值 + 波动区间」，不是写死的曲线**。若三条线固定，玩家三局就摸清规律，经营会退化成"背答案"。随机性设计见 **2.4**。

**为什么这产生趣味**
- **前中期抉择**：晚成型拖后腿，养不养？（工资低是经济补偿）
- **后期回报**：反超时刻 = 玩家记忆点，也是自发分享的素材
- **与铁人模式联动**：晚成型前期弱 = 更容易死，铁人模式下高风险高回报
- **重玩价值**：每局招募到的原型组合不同 → 每局队伍构成与故事都不同

**风险**：原型若失衡会重演"召唤师统治"（调研报告：策略空间坍缩到 ~8 套）→ 必须封测验证，见第 7.4 节。

### 2.2 成长路径自我选择 · 角色意志

**触发节奏**：建议 **每 2 层一次 + Boss 层必触发**（每层一次太频繁，会稀释重量）。

**流程**
1. 系统基于 **原型 + 性格 + 近期经历**（重伤 / 险胜 / 队友阵亡 / 连胜）生成 2–3 个成长方向
2. 每个方向 = **属性结果 + 角色台词**（性格化文本，不是"攻击+5"）
3. 玩家从中选择其一 → 角色成长（**引导，而非剥夺决策权**）
4. 性格"固执 / 独立"的角色有偏好：玩家选非偏好项 → 士气小幅下降，或需消耗资源"说服"

**成长方向示例**
| 情境 | 提案 A | 提案 B |
|---|---|---|
| 晚成型经历队友阵亡 | 「我要变强，不再让同伴倒下」→ 攻击向 | 「我要能挡在前面」→ 防御向 |
| 专精型连胜 | 「我摸清了他们的出招规律」→ 暴击/破防向 | 「我想学点保命的本事」→ 生存向 |
| 贪婪性格变强后 | 「加钱，不然我出力打折」→ 战力+ 但 **薪资↑** | （取舍：要战力还是要钱） |

**设计要点**
- 选项是"角色想成为什么"，文本必须带性格——**这是"有血有肉"的载体**
- 玩家仍拍板（保留 agency），但选项由角色给出（角色有意志）
- 选择**记入传记**：「L12 选择了复仇之路」

**价值**：角色从"玩家手里的数值泥巴"变成"有自己想法的人"，玩家身份从操盘手变成**教练 / 经理**。

---

### 2.3 工资与经营压力 · 让钱有张力

**基本规则**
- 每个角斗士有**层薪**（基于战力 / 星级 / 声望 / 性格系数）
- 建议 **每 5 层结算一次**（对齐 Boss 节奏，形成周期压力）
- **涨薪触发**：升星、击败 Boss、成长选择变强、声望提升
- **性格系数**：贪婪 ×1.3 且频繁要求加薪；忠诚 ×0.85 且危难时可降薪留队

**欠薪后果（渐进）**
1. 欠薪 1 次 → 士气下降，战力小幅衰减
2. 连续欠薪 → 拒绝出战
3. 长期严重 → 离队 / 背叛（可能带走装备）

**核心抉择：裁员 / 卖人**
养不起时裁谁？——早熟型后期性价比低但功劳大 / 晚成型便宜但还没回本 / 老兵有感情但最贵。
**这比阵亡更纠结：阵亡是意外，裁员是你亲手决定的。**

**与原型咬合成的漂亮循环**
> 早期低价签下晚成型（他弱所以便宜）→ 忍他拖后腿 → 省下的工资投装备 → L35+ 他反超 → **情感与策略双回报**。玩家会记得"我差点裁掉他"。

**价值**
- 经营压力真实化：钱不只是"买装备"，还要"养人"
- 裁员成为**最强的人格化时刻**（有情感重量的主动抉择）
- 让已有资源（金币）获得新的用途与张力，不新增货币

### 2.4 随机性与多样性（链路不可预测）

> **设计原则：随机决定「发生了什么」，玩家决定「如何应对」。**
> **70% 可预期（能规划）+ 30% 意外（需临场判断）。**

**为什么必须随机**（修正 v2 初稿中"原型固定"的倾向）：
若成长曲线写死，玩家三局即摸清"晚成型 L37 反超"，经营就从**判断与取舍**退化为**背答案与数值优化**——这恰恰是本方案要解决的老毛病。链路的可预测性会杀死惊喜感，而惊喜感正是"有血有肉"的来源。

**随机性的五个来源**

| # | 来源 | 机制 | 效果 |
|---|---|---|---|
| 1 | **成长幅度波动** | 原型成长率是**期望值**，每次实际成长在区间内波动（如晚成型 ×1.2~×1.6） | 无法精确预测何时反超 |
| 2 | **成长选项池随机** | 每原型+性格对应 15–20 个成长选项，每次**加权随机抽 2–3 个** | 同原型不同 build：这局复仇流，下局守护流 |
| 3 | **觉醒 / 突破事件** | 低概率（5–10%）打破原型预期：晚成型提前爆发、早熟型二次成长、专精型补足短板 | 触发即是故事，玩家会记住 |
| 4 | **隐藏潜能** | 招募时不可见（或显示"未知"），特定条件后显现（天赋异禀 / 玻璃体质） | 招募有赌博感，每个角色是待发现的谜 |
| 5 | **经历驱动的随机** | 重伤后随机「浴火重生」(+属性) 或「留下旧伤」(-属性)；队友阵亡触发不同方向 | 经历真的改变角色，不只是被记录 |

**多样性与策略感的平衡（关键）**
- **保留可规划的部分**：原型**倾向**大概率可预期 → 玩家能判断"我签了个潜力股"
- **交给随机的部分**：具体幅度、抽到的选项、特殊事件 → 玩家需临场判断与取舍
- **不能随机到无法规划**：若完全不可预期，经营就变成纯赌博，策略乐趣同样消失

**与"经营"的关系**：经营的乐趣 = **在不确定性中做资源决策**。全可预测 → 解数学题（无趣）；有随机 → 判断与取舍（有趣）。

**验收标准**：同一原型在 100 局模拟中，实际终值应呈**分布**而非单点；「觉醒」「哑火」等离群轨迹各占 5–10%，且**哑火型的存在是必要的**——它让裁员成为真实抉择，而不是走过场。

### 2.5 风格化体系（Thematic Stylization）· 让差异被"感受"而非"读取"

> 问题：若三个原型只是数值曲线不同，玩家仍只在看数字。风格化 = 给每个原型 / 特性一套**身份识别语言**（命名调性、叙事口吻、视觉母题、轻量表现），让差异直接进入感官与情绪层——与 2.4 随机性咬合：随机决定"发生了什么"，风格化决定"这是谁、什么气质"。

#### 2.5.1 三原型的"气质"（核心风格母题）

| 原型 | 风格母题 | 命名 / 叙事调性 | 视觉母题（Canvas 方块可行范围内） |
|---|---|---|---|
| **早熟型** | 神化 / 天选 | 「他生来就该站在最前面」。霸气、笃定、略带不屑。台词如「敌人还没看清，已经结束了」 | 金白光环 + 神圣纹章；开局即"发光"，边缘稳定不外溢 |
| **专精型** | 极致 / 偏科 | 「别的我不管，这一项，无人能及」。冷静、理性、专注。台词如「数据不会说谎，弱点暴露了」 | 单色高饱和聚焦（纯蓝数据流 / 纯红刀芒）；其余维度视觉"灰化" |
| **晚成型** | 无界膨胀 / 破界 | 「他还远没到头」——**没有天花板、越往后越碾压的无限膨胀感**。前期沉默倔强，后期越成长越平静、越压迫。台词如「你以为这是极限？」 | **随层数持续放大的体感**：方块边缘随成长溢出 / 涨破边框（"破界"特效），光环由暗转炽。传递"永远在长、没有上限"的压迫式成长爽感 |

> **晚成型"无限性"的落地口径**：你要的那股"无限膨胀"的劲，用**破界 / 无界膨胀**主题承载——它是"成长没有上限、雪球永不停止"的力量感爽点，落到表现层是**方块随层持续放大 + 光环溢出破框**的轻量特效（不引入写实体型 / 3D 渲染，守住三人冒险基调与现有 Canvas 方块约束）。风格化服务于"感受差异"，不靠写实体型演出。

#### 2.5.2 其他特性也要风格化（"其他的也有类似"）

风格化不止三组原型——凡能形成记忆点的特性都该有自己的"声纹"：

| 特性类型 | 风格化手法 | 例子 |
|---|---|---|
| 性格标签（贪婪 / 忠诚 / 固执 / 独立…） | 专属图标 + 口吻 + 决策倾向 | 贪婪开口谈钱；忠诚危难时主动降薪 |
| 隐藏潜能（天赋异禀 / 玻璃体质 / 未知） | **盲盒揭晓**演出：招募时"未知"，条件达成瞬间风格化高光 | 天赋异禀=金光炸裂；玻璃体质=脆裂预警纹 |
| 觉醒 / 突破事件 | 打破原型的**风格化高光时刻**，与常态母题对比 | 晚成型提前爆发=破框特效骤亮 |
| 经历印记（重伤 / 旧伤 / 连胜） | **可见的视觉印记**叠加在方块上 | 旧伤=裂痕纹章；连胜=战意流光 |
| 裁员 / 告别 | 专属叙事调性（克制、有重量，不煽情过度） | 老兵退役=慢镜 + 留白台词 |

#### 2.5.3 风格化原则与边界

- **风格化 = 身份识别系统**：目标是玩家**不看数值条**也能凭气质区分三个角色（"那个金光的是太一型，那个一直在涨的是阿和型"）。
- **可种子化**：所有风格化随机（潜能揭晓 / 觉醒高光）走既有 RNG，禁 `Math.random`。
- **表现层克制**：主要靠**命名 + 叙事口吻 + 图标 / 配色 + 方块轻量缩放 / 光晕**实现，不碰 3D、不做演出（守 Non-goals）。
- **调性统一**：整体走"三人冒险"基调，爽感来自成长与抉择，不靠低俗 / 猎奇刺激。

#### 2.5.4 风格化验收

| 指标 | 目标 |
|---|---|
| 盲测识别率 | 仅凭风格（不看数值）能正确区分 3 原型的占比 ≥ 70% |
| 成长选择口吻契合度 | 玩家能感到"这就是他说话的方式"（问卷 / 访谈） |
| 风格化记忆点 | 离局后能复述至少 1 个角色的风格母题 |

## 3. 人格化五层（与新机制的关系）

| 层 | 内容 | 优先级 | 与三个新机制的关系 |
|---|---|---|---|
| L1 身份 | 名字、性格、出身 | **P0** | += **成长原型**（太一/光子郎/阿和型） |
| L2 传记 | 幸存层数、重伤、并肩队友 | **P0** | += 记录**成长选择**的路径 |
| L3 失去 | 阵亡/退役的告别、纪念堂 | **P0** | += **裁员/卖人**（主动失去，比阵亡更纠结） |
| L4 关系 | 羁绊、宿敌、师徒 | P1 | 可基于成长经历自动形成 |
| L5 事件 | 受伤、加薪、背叛 | P1 | += **加薪谈判 / 成长提案 / 欠薪危机** |

## 4. 优先级与最小闭环

**Sprint 1（P0 · 最小可验证）**
1. 成长原型（3 种，含数值与英雄卡展示）
2. 成长路径自我选择（每 2 层 + Boss 层）
3. 传记（记录成长选择与经历）

> **验证命题**：玩家是否开始在乎某个角色的成长？（看成长选择页停留、晚成型是否被养到 L30+）

**Sprint 2（P1）**
4. 工资系统 + 欠薪后果
5. 裁员 / 卖人 + 告别叙事

> **验证命题**：玩家做裁员决策时是否感到纠结？（看决策时长、是否回看传记）

**Sprint 3（P2）**
6. 阵亡告别 + 纪念堂
7. 关系（羁绊/宿敌/师徒）
8. 完整事件池

**不要一次铺满。** Sprint 1 验证"角色活起来了"再投 Sprint 2——这正是过去半年踩过的坑（系统越加越重，前台没变丰富）。

---

## 5. Non-goals（明确不做）

- ❌ 不做全语音 / 3D 演出（表现层先文本 + 图标）
- ❌ 不做复杂对话树（成长选择保持 2–3 选项）
- ❌ **不让角色完全自主成长**（玩家必须保留最终拍板权，否则剥夺 agency）
- ❌ 不替换现有经济体系（工资是**新增消耗口**，不动装备/锻造/商店数值）
- ❌ 不改战斗引擎核心规则（但属性成长必然触及 core，见 7.2）
- ❌ 不做开放世界 / 地图探索
- ❌ 不引入 `Math.random`

## 6. 成功指标（可观测）

| 指标 | 目标 | 说明 |
|---|---|---|
| 晚成型养到 L30+ 的比例 | 高于早熟型 | 证明"养成"有效、玩家愿意忍 |
| 成长选择页停留时长 | 显著高于普通确认弹窗 | 在乎的信号 |
| 传记页打开率 | ≥ 40% | 情感投入 |
| 手动改名率 | ≥ 15% | 情感投入的直接信号 |
| 裁员决策时长 | 可观测，越长越好 | 纠结 = 人格化生效 |
| 招募 → 立刻替换率 | 下降 | **反向指标**，仍极高说明无效 |
| 同原型终值离散度 | 呈分布而非单点 | 随机性生效，见 2.4 验收 |
| 单局平均层数 | 提升 | 长期投入带来更深的局 |

> 现有埋点未覆盖以上事件，需先补遥测（扩展调研报告第 2.3 节清单）。基线待测。

## 7. 工程约束与风险（硬约束）

1. **确定性铁律**：原型分配、成长提案、工资谈判的一切随机**必须走既有种子化 RNG**，禁 `Math.random`，否则破坏 parity（5 种子逐 bit）与 `guard-determinism`。
2. **core 影响评估（新机制必然触及 core）**：
   - 成长原型 → 属性成长曲线 → **必须进 `packages/core`**
   - 成长选择 → 属性变更 → 走既有 command 机制，落 core
   - 工资 → 若在休整期结算，可能在状态层而非战斗结算层（需评估是否进 core）
   - **凡进 core 者，必须 `build:core --sync` 同步 Edge 端 + 过 parity**
3. **存档兼容**：新增字段（原型 / 成长历史 / 薪资）需迁移方案，或明确提示清档（参考 v2.0.0 号段回退的破坏性先例）。
4. **平衡风险（最高）**：三原型失衡会重演"召唤师统治"（策略空间坍缩 ~8 套）。建议复用 10,080 场封测脚本思路，对三原型做胜率/层数分布模拟，先跑数据再定数值。
5. **范围风险**：人格化极易膨胀为叙事项目。坚持文本 + 图标，**不追演出**。
6. **表现层限制**：战斗仍是 Canvas 方块 + HP 条、无地图/瓦片。L3 告别/纪念堂**先在 UI 层实现**，不依赖战斗表现升级——避免被表现层卡住。

## 8. 待确认（需拍板）

1. **成长触发频率**：每层 / 每 2 层 / 每 5 层？（建议每 2 层 + Boss 层必触发）
2. **原型的刚性程度**：~~固定~~ → **修正为「倾向 + 波动 + 低概率变异」**（见 2.4）。完全固定会让链路可预测、失去惊喜；完全随机会让玩家无法规划。待定：波动幅度与觉醒概率的具体数值。
3. **工资结算周期**：每 5 层（对齐 Boss）还是每层？
4. **裁员是否永久失去**：建议是，否则失去没有重量。
5. **原型数量**：先做 3 种，还是加第 4 种「均衡型」？
6. **工作量重估**：成长/原型必然影响属性 → 已确定要动 core，"性格是否进战斗结算"这个原问题需并入整体工作量重估。
7. **风格化强度**：是否接受"晚成型方块随层放大 + 破框光晕"这类轻量表现（Canvas 方块约束内）？还是先纯文本 + 图标、表现层留到 Sprint 3？风格化母题的命名/调性是否认可（神化/极致/无界膨胀三套）？
