# 无限勇者竞技场 · 本地版 v1.2.0 前端 UI 升级说明

> ⚠ **版本体系已统一**：本仓自 **v2.0.0** 起收敛为**单一版本基线** —— `package.json`、`CORE_VERSION`、git tag、压缩包、线上 Pages、全部文档共用唯一版本号 `2.0.0`。本文标题与正文中出现的其它 `vX.Y.Z` 均为**历史里程碑代号**，不再具有发布号效力（详见 `docs/INDEX.md`「版本体系」）。

> 配套代码版本：`package.json` `1.1.0 → 1.2.0`（前端设计系统独立小版本，结算/数据层未变，回放契约 `CORE_VERSION` 不动）。

## 1. 现状分析（升级前）

逐项检视 `src/index.css` 与全部 `src/screens/*` 后发现：

| 维度 | 升级前状态 | 问题 |
|---|---|---|
| 设计令牌 | 仅有零散颜色变量，无间距/圆角/阴影/动效尺度 | 样式数值散落各组件，节奏不统一 |
| 表面材质 | 面板有渐变 + 内高光，但边框偏重（2px）、阴影单层 | 扁平、缺乏"实体感" |
| 弹层 | `App`/`ConfirmDialog`/`HeroPanel` 各自大段 inline 遮罩样式 | 三处重复、难统一、易漂移 |
| 模式选择 | `MainMenu` 用 3 个并列 `button`，`.mode-btn` 类**未定义** | 没有"单选控件"的视觉语义，键盘可达性弱 |
| 可达性 | 仅 `button:focus-visible`；全局无 `:focus-visible`、无滚动条/选区样式、无 `color-scheme` | 暗色下原生滚动条刺眼、键盘焦点不连续 |
| 微交互 | 悬停/按下有基础态，但无抬升/辉光、无入场动画 | 偏"静态"，质感不足 |

结论：**底层框架（确定性引擎、移动适配、reduced-motion）是好的**，缺的是"统一的设计语言 + 材质深度 + 系统级可达性"。

## 2. 升级内容（v1.2.0）

### 2.1 设计令牌体系（`:root`）
新增并规范化：
- 间距尺度 `--s-1..6`（4/8/12/16/24/32）
- 圆角尺度 `--r-xs..xl` + `--r-pill`
- 阴影/高程 `--elev-1/2/3`、`--ring-inset`、`--glow-accent/blue`
- 字号尺度 `--fs-xs..display`
- 动效 `--dur-fast/.18s`、`--ease`、`--ease-out`
- 语义色补全：`--ok-hi/--danger-hi/--warn/--text-2` 等，提升对比度
- `color-scheme: dark`

### 2.2 表面材质升级（纯 CSS，零资源新增）
- `.panel`：渐变 + 1px 内高光 + 顶层细高光线（`::before`）+ 分层落地阴影；新增 `.panel.accent` 金顶主面板。
- 按钮：悬停**抬升 1px + 辉光**，按下回弹 + 内阴影；`.primary` 悬停辉光增强。
- 卡片 `.hero-card`：悬停抬升 + 边框辉光。
- 全局 `::selection` 金染、`*` 暗色细滚动条（webkit + firefox）。

### 2.3 弹层系统统一（去除三处重复 inline）
新增 `.overlay`（遮罩 + 毛玻璃 + 居中 + 入场动画）、`.overlay--top`（z 90，压过角色面板）、`.sheet`（表面材质 + 入场动画）、`.sheet--danger/--info`、`.fx-busy`、`.depart` 过场类。
- `App.tsx`：出征台词 / 全局动画锁改走类名。
- `ConfirmDialog.tsx`：大段 inline 表面 → `.sheet` + `.sheet__title/body`，危险态改类名。
- `HeroPanel.tsx`：外层遮罩 + 内层表面接入 `.overlay`/`.sheet`，保留按职业色动态描边。

### 2.4 模式选择升级为分段控件
`MainMenu.tsx` 的 3 个模式按钮包进 `.seg`，改用 `.seg-btn`，并补齐 `role="radiogroup"/"radio"` + `aria-checked`，键盘可完整操作。视觉上"单选互斥"语义一目了然。

### 2.5 可达性 & 性能
- 全局 `:focus-visible` 金环（按钮/滑块/分段/开关全覆盖）。
- 滑块 `speed-range` 聚焦环 + 悬停放大；`.speed-chip` 聚焦环。
- 新增 `.toggle` 开关式按钮类（无障碍双通道等开/关语义复用）。
- 全部动画受 `prefers-reduced-motion` 约束（已存在并保留）。
- **渲染资源不变**：纯 CSS，无图片、无 web 字体下载（字体走系统栈 `ui-monospace…`）。构建产物 CSS `18.6 kB / gzip 4.8 kB`，与升级前同量级。

## 3. 验收

- `npm run build`：通过（116 模块，CSS 4.8 kB gzip）。
- `npm run verify`：**typecheck → 确定性 guard → smoke → integration → 21/21 backend 契约全部 PASS**（结算/回放/幂等未受 UI 改动影响）。
- 手动核对：所有既有类名（`.panel/.title/.hero-card/.speedbar/.eval-*`/`.tut-*`/`.anim-*` 等）行为保持，仅材质与动效增强。
