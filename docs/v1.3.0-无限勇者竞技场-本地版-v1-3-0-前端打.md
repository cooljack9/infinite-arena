# 无限勇者竞技场 · 本地版 v1.3.0 前端打磨说明

> ⚠ **版本体系已统一**：本仓自 **v2.0.0** 起收敛为**单一版本基线** —— `package.json`、`CORE_VERSION`、git tag、压缩包、线上 Pages、全部文档共用唯一版本号 `2.0.0`。本文标题与正文中出现的其它 `vX.Y.Z` 均为**历史里程碑代号**，不再具有发布号效力（详见 `docs/INDEX.md`「版本体系」）。

> 配套代码版本：`package.json` `1.2.0 → 1.3.0`（前端观感独立小版本，结算/数据层/回放契约 `CORE_VERSION` 未动）。
> 本版目标：在 v1.2.0 设计系统之上，把"战斗 HUD / Canvas 战斗观感 / 休整页 / 结算与主菜单 / 全局提示"四处短板补齐，全部为纯渲染层改动，**零确定性引擎改动**，故 21/21 后端契约与回放 parity 不受影响。

## 1. 升级范围总览

| 选项 | 模块 | 改动性质 | 风险 |
|---|---|---|---|
| 1 | BattleScreen HUD（DOM） | 玻璃化顶栏、技能冷却扫描遮罩、天气/精英胶囊、胜负横幅入场 | 无（纯 CSS + 类名） |
| 2 | Canvas 单位战斗（frame.ts / sprites.ts） | HP 条渐变+高光+低血脉冲、阵营脚环辉光、主题地台暗角+网格 | 无（仅绘制，不动 sim 数学） |
| 3 | 休整页（IntermissionHub / EqCard / ForgeTab / ShopTab） | `.seg` 分段导航、`.loot`/`.guide`/`.card` 材质、融合进度条 | 无（类名 + 结构微调） |
| 4 | 结算 / 主菜单 / 全局 Toast | ResultScreen MVP 高亮卡 + 胜负 big-num 入场 + 奖励图标化；MainMenu 面板 accent；新建全局 Toast 组件 | 无（新增独立 store，不污染游戏状态） |

**明确未做**（确定性/风险考量）：Canvas 飘字、命中白闪、死亡粒子——这些需要 sim 层事件钩子或额外状态，可能触及确定性契约，故本期跳过，留待后续独立评估。

## 2. Option 1 · 战斗 HUD 像素级打磨

- `.hud`：加 `background: var(--glass); backdrop-filter: blur(8px); border:1px solid var(--line); border-radius: var(--r-lg); box-shadow: var(--elev-2)`，玻璃质感顶栏。
- `.skill-btn`：相对定位 + 内阴影；`.skill-cd` 改为从顶部向下的暗色遮罩 + 剩余秒数居中（`font-variant-numeric: tabular-nums`），并加 `linear-gradient` 扫描线动效，冷却可读性与"正在转"的反馈更强。
- `.weather-chip` / `.elite-chip`：天气与精英 Boss 改为带图标光晕的胶囊（`weather-icon` 辉光 + 语义色），不再用裸 inline 文本。
- `.banner` + `bannerIn` 关键帧：胜负中央大字入场动画（替代原先 `countdown-pop` 的单纯缩放），更有"落定"感。
- `BattleScreen.tsx`：天气/精英/横幅三处 inline 样式迁移到类名，组件更干净、状态一致。

## 3. Option 2 · Canvas 单位战斗观感（仅绘制）

- **HP 条**：底色黑描边保留；血条改为垂直渐变（顶部高光→主色）+ 顶端 1px 白色高光带；低血（<30%）触发 `lowHpPulse` 透明度脉冲，更醒目。色盲双通道（蓝/橙）与召唤物蓝灰保持不变。
- **阵营脚环**：在原有 `ellipse` 脚环外加一层同色 `shadowBlur` 辉光（友方金/敌方红；色盲态用 CB 安全色 + 虚线），"谁是谁"一眼可分，且仍是"视觉即判定"的真实半径。
- **主题地台**：`render()` 在铺砖前先画一层主题色径向暗角（vignette）+ 极淡网格，地面不再"平涂"，纵深感提升。仍基于 `skin` 主题色，无新增资源下载。
- 未触碰 `BattleSim` / `planBattle` / 任何数值或随机源 → 回放 checksum 不变。

## 4. Option 3 · 休整页材质化

- `.seg` 分段控件：三套子页（穿戴/融合/商店）导航改为 `role="tablist"` + `.seg-btn`（`aria-selected`/`aria-controls`），键盘可完整切换；推荐项用 `.seg-btn.recommend` 绿描边提示。
- `.loot`：待开宝箱改为虚线品质色边框 + `chest-open` 动画的卡片类（原先散落 inline）。
- `.guide`：「建议下一步」渐进引导盒统一为虚线绿边 + 淡绿底类。
- `.card` + `.rarity-{normal,blue,orange,red}`：装备/消耗品/招募卡统一卡片材质（渐变 + 内高光 + 品质色描边 + 品质色辉光），`EqCard` 直接复用，ForgeTab/ShopTab 的卡片网格改走 `.card` 网格。
- `ForgeTab` 合成台新增 `.progress` 进度条（本层剩余融合次数可视化）。

## 5. Option 4 · 结算 / 主菜单 / 全局 Toast

- **ResultScreen**：
  - MVP 高亮卡 `.mvp-card`：从 `battleEval` 快照取本场 MVP（友方伤害+治疗最高），独立高亮展示姓名/职业/贡献值，呼应战报屏。
  - 胜负 `big-num` 入场：`.result-num` 加 `bannerIn` 入场动画。
  - 奖励/操作按钮图标化（`↻ 再来一局` / `🏠 主菜单` 等），更紧凑。
- **MainMenu**：主面板加 `.panel.accent` 金顶材质，与全局设计语言统一。
- **全局 Toast**：新建 `src/components/Toast.tsx` + 独立 `toastStore`（zustand，与游戏 store 完全隔离，不污染存档/状态）。`ToastHost` 挂载于 `App.tsx`，玻璃胶囊 + 滑入动画 + `aria-live="polite"`，用于"开箱完成""已领取"等轻提示。休整页开箱流程接入 `toast()`。

## 6. 验收

- `npm run build`：通过（117 模块，CSS 约 23.5 kB / gzip 5.7 kB；纯 CSS，零图片/字体下载，渲染资源仍低）。
- `npm run verify`：**typecheck → 确定性 guard → smoke → integration → backend 21/21 全部 PASS**（UI 改动不触及引擎/契约/回放）。
- 手动核对：所有既有类名（`.panel/.title/.hero-card/.speedbar/.eval-*`/`.tut-*`/`.anim-*`/`.seg` 等）行为保持，仅材质与动效增强；新增 `.hud/.skill-cd/.weather-chip/.elite-chip/.banner/.loot/.guide/.card/.rarity-*/.progress/.mvp-card/.result-num/.toast*` 均为增量，无破坏性覆盖。
