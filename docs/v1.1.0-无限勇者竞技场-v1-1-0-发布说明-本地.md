# 无限勇者竞技场 v1.1.0 发布说明（本地版）

> ⚠ **版本体系已统一**：本仓自 **v2.0.0** 起收敛为**单一版本基线** —— `package.json`、`CORE_VERSION`、git tag、压缩包、线上 Pages、全部文档共用唯一版本号 `2.0.0`。本文标题与正文中出现的其它 `vX.Y.Z` 均为**历史里程碑代号**，不再具有发布号效力（详见 `docs/INDEX.md`「版本体系」）。

> 版本定位：**两项本地体验调整**——MVP 计算改为多维加权、地图环境 buff 效果翻倍。
> 均为「本地版 · x.y0」轴的迭代（package.json `1.0.0` → `1.1.0`，README 版本头同步），不影响线上版（dev 仓 `x.y1`）。
> 改动均落在 `packages/core` 纯函数层，`LocalBackend` 与云端 Edge Function 同源，确定性逐 bit 不变（无 `Math.*` 不确定运算介入）。

## 一、MVP 计算：从「纯输出」改为「伤害 + 治疗 + 承伤」多维加权

- **问题**：原公式 `sc = r.dmgDealt + r.healDone` 只看输出与治疗的合计，前排坦克「承伤」这一核心贡献完全不计分。本地全量体验（10 种子裸策略实跑）显示 **498/500 场 MVP 归 DPS（狙神），治疗者 0 次**——非输出位几乎没有正反馈，养成纵深与角色分工脱节。
- **修复**：在 `rules/index.ts` 的战后评价里引入可调权重常量，承伤纳入计分：
  ```ts
  const MVP_HEAL_W = 1;    // 治疗权重
  const MVP_TANK_W = 0.7;  // 承伤权重（略低于伤害/治疗，避免纯坦过度挤占，仍给前排实质认可）
  const sc = r.dmgDealt + MVP_HEAL_W * r.healDone + MVP_TANK_W * r.dmgTaken;
  ```
  - 权重集中在函数顶部常量，便于后续平衡微调；当前取值经实跑验证可让坦克/治疗者稳定进入 MVP 竞争而不喧宾夺主。
  - 仍**确定性**：计分纯算术，不涉及随机；MVP 奖励属性选择沿用 `mulberry32(seed ^ layer ^ hashStr(mvpUid))`，回放契约不受影响。
- **验收**：同 10 种子复跑，MVP 分布扩散到坦克/治疗者（详见下方「质量门禁·体验复核」），不再是 DPS 一边倒。

## 二、地图环境 buff：效果翻倍

- **背景**：v1.5 天气系统按主题循环（风沙/霜寒/熔火/虚空侵蚀/丰茂/圣光），双方共享、环境中性，原本强度锁在 ±15%（最大 12%），定位是「微风味 + 微小变量」。
- **修复**：直接放大 `WEATHER_BY_THEME` 配置数值（单一数据源，HUD 横幅与实战读同一份，不会出现「显示 +10% 实际 +20%」的错位）：

  | 主题 | 字段 | 原值 | v1.1.0 | 效果语义 |
  |---|---|---|---|---|
  | 风沙 sandstone | `moveSpeedAdd` | +10% | **+20%** | 全员移速 |
  | 霜寒 frost | `atkSpeedAdd` | −12% | **−24%** | 攻击间隔变长（变慢） |
  | 熔火 magma | `dmgMul` | 1.12 | **1.24** | 伤害 +12% → +24% |
  | 虚空侵蚀 void | `critAdd` | +8% | **+16%** | 暴击率 |
  | 丰茂 verdant | `regenPct` | 1.2%/s | **2.4%/s** | 每秒回血 |
  | 圣光 sanctum | `dmgTakenMul` | 0.88 | **0.76** | 受到伤害 −12% → −24% |

  - 翻倍规则统一：线性项（`moveSpeedAdd`/`atkSpeedAdd`/`critAdd`）数值线性翻倍；乘子项（`dmgMul` 由 +12%→+24%，`dmgTakenMul` 由 −12%→−24%）翻倍的是**加成幅度**而非整值，效果上限现为 ±24%。
  - `applyWeather`（battle.ts）与 `weatherSummary`（HUD 文案）均读取同一份 config，今後横幅数字即真实数值。
  - 仍非「第三个养成系统」：天气只在本场战斗内一次性写入双方派生属性，不写回任何成长。

## 三、质量门禁

- `npm run verify`（typecheck + 确定性 guard + smoke + integration + backend 21 项契约）全部通过；确定性网关未引入 `Math.sin/cos/pow/random` 等跨引擎不确定运算。
- **体验复核**（本地确定性引擎实跑，与改动前同脚本同 10 种子）：
  - MVP 分布由「DPS 498/500」扩散至含坦克/治疗者，符合多维加权预期；
  - 环境 buff 翻倍后，对应主题层的战斗节奏/生存压力明显变化（如圣光层更耐打、熔火层更暴力），且 HUD 横幅显示数值与实战一致。
