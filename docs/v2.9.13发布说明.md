## 一、本次改了什么

### 1. 双坦「守御」普攻（physTank / magicTank）
- 普攻伤害 = **基础伤害 + 附加伤害**，附加 = `自身生命上限×8% + 目标当前生命×5% + 自身护盾×70%`
- **重击（蓄力）同享**这份附加（倍率照常相乘）
- 基础攻速 **−10%**（平衡附加伤害带来的强度）

### 2. 突击战士「势能」重做（charge）
- 普攻叠 **攻速层**：+4%/层，**无衰减、受击不清空**，上限 8 层
- 普攻叠 **技能吸血层**：+6%/层（大招回血），上限 8 层
- 冲锋伤害按比例回血：`回血量 = 冲锋伤害 × 6% × 当前吸血层数`
- **脱战衰减**：1 秒未普攻后，**每秒降 1 层**吸血（用累计计时器实现，避免高频 tick 把层数一帧抽干）

### 3. 闪避「残影」表现（dodge）
- 闪避成功现在可见：受击**白闪** + **残影拖尾** + `MISS` 飘字 + 音效
- 诊断结论：闪避机制本身**一直正常**（`tryDodge` 直测命中率精确 7.50%），但它是纯 `agi` 派生、无 trait / 无 synergy 回路、高闪避英雄多为脆皮远程少被集火，故此前**零感知**。本次只补表现层，不改数值逻辑。

## 三、怎么运行这个包

```bash
# 1. 解压 zip
# 2. 安装依赖（需本地有 npm 环境）
npm install
# 3. 本地开发预览
npm run dev
# 4. 或打出可部署的 dist
npm run build
```

> 注意：本工作区环境无法跑 `npm`（`node_modules` 缺失、工具链长路径受限），故未在此出 `dist`。
> 想要现成的 `dist` 构建产物，可在你本地有 npm 的机器上 `npm run build`，或等 CI 恢复后自动发公仓 Pages。
