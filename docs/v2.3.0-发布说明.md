# 无限勇者竞技场 · v2.3.0 发布说明

> **版本体系（v2.0.0 起 · 单一版本基线）**：本版本号 `2.3.0` 与 `package.json`、`CORE_VERSION`、git tag、压缩包名、线上 Pages 共用同一个号（末位恒为 0）。
> 本版本为**纯前端性能 / 表现优化大版本**：`packages/core` 引擎**零改动**，确定性逐 bit 一致，回放契约与 2.2.0 完全兼容（旧 replay / 存档可复用，无需清库或强制刷新）。

| 维度 | 说明 |

## 二、特性清单

### ① 仿真移入 Web Worker（终极降运算量杠杆）
- 新增 `src/render/SimController.ts`：`SimSurface` 只读渲染表面接口 + `DirectSim`（主线程直驱，默认路径零回归）+ `SimClient`（Worker 模式）+ 工厂 `makeSimController`。
- 新增 `src/render/simWorker.ts`：Worker 入口，持有真实 `BattleSim`，按固定 20Hz 步长 `tick`，周期性 `postMessage` 回传「渲染快照 + 音频线索 + 结算数据」。
- 主线程战斗期近乎空闲，只负责「收快照 + 渲染」，长局多单位时主线程帧预算显著释放。
- **开关与兜底**：仅 `?simworker=1` 且本地模式启用；远程模式（服务端权威）强制 `DirectSim`；Worker 创建 / 初始化失败自动回退 `DirectSim`，「开开关不比不开更差」。
- 抽出 `src/game/simArgs.ts`（store-free 纯函数），Worker 与默认路径共用同一套装配逻辑，保证 parity 一致。

### ② 渲染热路径去 `shadowBlur` + 自适应 FPS 降载
- 清除 Canvas 2D 热路径仅剩的两处 `shadowBlur`（脚环、暴击飘字）：暴击飘字改为**预渲染辉光精灵**（`getCritGlowSprite` 64px 烘焙一次 + `globalCompositeOperation='lighter'` 叠加）；脚环改为半透明加宽描边光晕。
- 主循环加**帧时间 EMA 自适应降载**：持续 >22ms 压粒子 / 关辉光，<14ms 回升，**永不超过用户所选质量档位**（低配 / 长局自动兜底，不盲目降质）。

### ③ 亮色主题 + aurora 省电降级
- 新增 `light` 主题（`index.css` 全 CSS 变量 token 覆盖，暖纸底 + 深墨字，零改组件换肤）。
- aurora 流动背景纳入「省电」档关闭（`data-quality="low"` 时 `body::after` 冻结、降不透明度）。

### ④ 打包瘦身
- 引入 `vite-plugin-compression2`：构建后预生成 `.br` / `.gz` 压缩资产（brotli + gzip，threshold 1024）。
- 配合既有 `React.lazy` 分包 + `manualChunks`（vendor-react / core / vendor），关键 chunk 体积与首屏传输量下降。

### ⑤ Worker 快照精简（降跨线程序列化 / GC 压力）
- **去每帧 `arena` 克隆**：`arena` 整场只读不写，`SimClient` 构造期即从 `plan.arena` 持有同一引用，快照不再携带。
- **每帧 `.filter()` 原地紧凑**：`ArenaCanvas` 的 `critFlt/burstRef` 由 swap-remove 原地紧凑，**零数组分配**。
- **Unit 字段白名单打包**：抽出 `src/render/packSurface.ts`（`UNIT_FIELDS` 48 字段 + `packUnit`），Worker 快照 `units` 由深拷贝完整 Unit（~110 字段，含嵌套 `skill/derived/primary/mountSkill`）改为仅打包渲染读取的 48 个扁平字段，最贵的嵌套对象深克隆被彻底跳过。

## 四、性能收益（相对 2.2.0）

| 优化项 | 收益 |
|---|---|
| Web Worker 仿真 | 主线程每帧 `tick` 退化为空转，仅维持插值；CPU 密集仿真移出主线程，长局掉帧风险下降 |
| 去 `shadowBlur` | 消除 Canvas 2D 最贵逐帧操作，热路径改为预渲染精灵叠加 |
| 自适应降载 | 低配 / 长局自动兜底，稳定帧率不崩 |
| 快照精简 | 每 50ms 跨线程克隆体积与 GC 压力显著下降（跳过嵌套对象与静态 `arena`） |
| brotli/gzip 预压缩 | 首屏 / 增量传输体积下降，关键 chunk 可 preload |

## 五、已知边界
- Worker 实际线程往返（`postMessage` / `structuredClone` / 插值手感）本环境未经真人浏览器验证；默认路径完全不动，`?simworker=1` 手动开启即可对比。若需回退，去掉该参数即瞬时回到主线程模式。
- 核心引擎未改动，故无 replay / 存档破坏性变更；线上发版按 CICD 手册走全链路 parity 闸门即可。
