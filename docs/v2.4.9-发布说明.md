# v2.4.9 发布说明 · 本地版 — 战斗特效像素化

> 对应计划：`docs/v2.4.9-本地版-战斗特效像素化-计划.md`

## 🎯 问题：特效和单位「两套渲染语言」打架

单位精灵（`sprites.ts`）早已是成熟像素管线：20×20 模板 + 材质分层 + 离屏光栅化 + nearest 放大。
但技能特效（`frame.ts` `drawEffect`）仍是另一套语言，并置时显得糊、飘、廉价：

| # | 问题 | 表现 |
|---|------|------|
| 1 | 语言不一致 | 单位 nearest 锐利像素；特效 `ctx.arc()/stroke()` 抗锯齿 + `lighter` 连续发光 |
| 2 | 无具象造型 | nova=9 条放射线、ring=圆、beam=直线、quake=8 条折线——没有火焰舌/晶体棱面/符文 |
| 3 | 未对齐像素网格 | 坐标半径连续变化 → 亚像素抖动（像素游戏「脏」的主因） |
| 4 | 无逐帧动画 | 进度 `p` 连续插值 = 平滑补间，非像素帧步进 |
| 5 | 单色无阶 | 直接用 `e.color` + 白高光，缺 暗→中→亮→白热 四阶色阶 |

## ✨ 方案：具象像素精灵（复用 sprites.ts 同一套纪律）

**用户拍板**：16×16 统一网格 · 全量覆盖（12 shape + 8 挥击）· beam/trail 像素段平铺 + 端点爆点。

### 新增文件

- **`src/render/pixelVfxTemplates.ts`**（375 行）— 20 个 16×16 像素母题，参数化像素几何生成后静态固化。
  四阶色阶字符：`.`=透明 `1`=暗轮廓 `2`=中间调 `3`=亮部 `4`=白热核心。
- **`src/render/pixelVfx.ts`** — 色阶派生 / 离屏光栅化缓存 / 像素绘制器 / beam-trail 平铺 / 抖动溶解。

### 关键技术点

| 项 | 做法 |
|----|------|
| 整数块缩放 | 目标尺寸吸附到 `blockPx × 16`，像素块永远等宽正方（非整数倍拉伸是「脏」的根源） |
| 坐标吸附 | 绘制中心 `Math.round` 到整数像素，杜绝亚像素抖动 |
| 光栅化缓存 | 每 `(造型/基色/档位/旋转档)` 只画一次，每帧仅一次 `drawImage`——比原「数十次 stroke + 合成态切换」更快 |
| 动画 | 不手绘多帧：整数块缩放（扩散）+ 4×4 Bayer 有序抖动溶解（消散）+ 色阶迁移（能量衰减），全部确定性 |
| 发光 | 像素级 bloom（亮索引向四邻溢出一圈），**禁用** `shadowBlur` / 大面积 `lighter` 渐变 |
| beam / trail | 沿方向**平铺 16×16 段**（段内沿 x 均匀 → 无缝），命中端挂端点爆点；不整体拉伸单张精灵（会把像素格子拉变形） |
| 挥击 | 8 种 `AtkKind` 全部像素化；混合模式改 `source-over`（`lighter` 会把白热芯吹成死白，抹掉色阶） |

### 保真细节

- 各 shape 半径**逐一复刻**原矢量公式：`ring/shock/nova` 随进度扩张，`bubble` 微呼吸，`quake/cage/blade/sun/rift/light` 固定——否则固定型特效会错误暴涨。
- `dashed` 起手距离环属**射程指示器**（辅助信息，非特效），保留矢量虚线语义。
- 母题缺失时 `drawPixelEffect` 返回 `false`，自动回退原矢量路径（安全网）。
- 像素精灵是单遍 source-over 实心块，原矢量是三层 `lighter` 叠加 → 给像素路径 ×1.4  alpha 补偿感知亮度（唯一观感调参点）。
