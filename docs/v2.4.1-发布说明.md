# 无限勇者竞技场 · v2.4.1 发布说明

> **版本体系（v2.0.0 起 · 单一版本基线）**：本版本号 `2.4.1` 与 `package.json`、`CORE_VERSION`、git tag、压缩包名、线上 Pages 共用同一个号。
> 本版本为 **2.4.0 的前端微优化补丁**：收敛 UI 界面主题为单套，省缓存、省首屏运行时。`packages/core` 引擎**零改动**，确定性逐 bit 一致，回放契约兼容 `2.2.0`（旧 replay / 存档可复用，无需清库或强制刷新）。

| 维度 | 说明 |

| 默认路径 | 100% 不变；去除的主题选择器本就默认 aurora，行为等同 `2.4.0` |

## 二、变更清单

### ① UI 界面主题收敛为单套 aurora（四套 → 初始一套）
- 原 MainMenu 提供 4 套可选 UI 界面主题：`aurora`（默认暖紫金）/ `neon`（霓虹深空）/ `ember`（余烬橙红）/ `light`（亮色）。
- 按"前端没必要四套风格，只微优化初始套装"的优化方向收敛：仅保留初始 `aurora`，删除其余三套。
- 删除内容：
  - `src/index.css`：移除 `:root[data-theme="neon" | "ember" | "light"]` 三套 CSS 变量 token 块（源码约 **-2.6KB / 2645B**），aurora 走 `:root` 默认变量，无显式块。
  - `src/screens/MainMenu.tsx`：移除"界面主题"分段选择器 UI。
  - `src/App.tsx`：移除监听 `theme` 并写 `document.documentElement[data-theme]` 的切换 effect（不再有运行时主题切换）。
  - `src/game/state/slices/types.ts`：`Theme` 类型由 `'aurora' | 'neon' | 'ember' | 'light'` 塌缩为 `'aurora'`；删除 `setTheme` action。
  - `src/game/state/slices/helpers.ts`：移除 `THEME_KEY` / `saveTheme` 与 `localStorage` 读取，`loadTheme()` 直接返回 `'aurora'`（启动省一次同步读）。
  - `src/game/state/slices/meta.ts`：`theme` 状态固定 `'aurora'` 常量，不再持久化切换。
- **地图主题皮（`MAP_THEMES`，战斗渲染皮肤）保留不动**：那是按关卡内容驱动的（`sandstone` / `ice` / `void` 等，与关卡数据绑定），不属于"用户可选的四套界面风格"，删之会让所有关卡视觉雷同，故不碰。

### ② 收益
- **省缓存**：首屏 CSS 体积下降（三套主题 token 不再进产物）；重复访问命中率提升。
- **省首屏运行时**：移除 `data-theme` 切换 effect 与主题 `localStorage` 读取，启动路径更短、无主题重算。
- 换肤能力保留为"改 `index.css` 的 `:root` 变量"这一低成本方式，组件零改动即可整体换肤。

### ③ core 引擎冻结（parity-safe）
- `packages/core` 零改动，`CORE_VERSION` 保持 `2.2.0`，确定性逐 bit 一致；旧 replay / 存档可复用，无破坏性变更。
