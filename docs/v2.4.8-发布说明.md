# v2.4.8 发布说明 · 本地版 — 全站像素风

> 对应计划：`docs/v2.4.7-本地版-整备界面拆分与像素风改造-计划.md`（批次 2）。

## 🎨 视觉改造（纯 CSS 令牌层，组件零改动）

与战斗画布的像素渲染语言（最近邻放大、有限色板、逐帧动画）全面对齐：

- **字体不像素化**（用户拍板：战斗内普通字体无违和感）：保持系统等宽栈，零字体下载、首屏体积零增量。
- **形状**：全部圆角归零（含 pill 标签、滑块圆点）——方块即像素风。收尾补硬：初版漏掉 7 处硬编码非 0 圆角（Firefox 滑块拇指 50%、教学云朵 22px、教学关闭/云朵 puff/教学下一步/帮助?按钮 50%、旋转提示 999px pill），已脚本归零；最终全文件 `border-radius` 仅 0 与令牌变量（令牌已全 0）。**视觉强化（用户验收反馈"看不出像素感"后补）**：仅归零圆角+硬阴影仍不够——扫描线原在 `z-index:0` 被不透明面板整体盖住、不可见。补强：实面加 2px 硬轮廓、块状投影加大（`--elev` 偏移 3/4/6px）、扫描线提至内容之上（`.app::after` z-index:9000 低透明度 CRT 叠层，`pointer-events:none`）——这才是真正读得出来的像素语言。
- **阴影**：去全部模糊——软投影硬化为 `2px 2px 0` 阶梯投影；辉光硬化为 `0 0 0 2px` 硬描边；inset 高光改 2px 亮暗 bevel。
- **动效**：缓动曲线全部改 `steps()` 帧步进（呼吸/流动动画同步），与战斗逐帧同语言；入场动画改 steps(3)。
- **全屏背景**：aurora 模糊辉光层（blur 48px）→ CRT 扫描线条纹（零动画、零合成成本）；毛玻璃 backdrop-filter 全部移除。

## ⚡ 开战响应提速（按用户约束修正预取时机）

根因：BattleScreen 懒加载 chunk 原挂在 `confirm()`（确认开战）那一刻下载，线上首战 1.2s 过场窗内可能下不完 → 台词播完掉进 Suspense「加载中」。

修正方案（保证「先布完阵容」因果）：
- **整备页（IntermissionHub）不预取**——布阵尚未开始就加载战斗屏会让数据与布阵操作脱节，已撤销该处预取并还原 `useEffect` 导入。
- **布阵页（PreBattle）挂载即预取**——玩家选增益/选队长/摆阵的整段时间都是下载窗口；`sim` 仍严格在 `confirm()` 时按**已定稿布阵数据**同步构造（`setFormation` 先于预取），因果链未断。
- 实测：布阵页打开后 chunk（约 60KB）在布阵操作期间即下载就绪，确认开战不再有 Suspense 兜底闪现。
