# v2.4.4 发布说明 — 四点优化合集

> 依据用户反馈逐项落地；core 引擎改动保确定性，guard/parity/smoke/integration/backend/test 全绿，
> parity 校验和与 v2.4.3 逐位一致、回放契约兼容。

## ① 通用数据回路（前后端查表卡顿）
- 新增 `packages/core/src/content/registry.ts`：**DB 统一索引 + LRU（容量 512）+ where 算子**（`$in`/`$nin`/`$ne`/`$gt`/`$gte`/`$lt`/`$lte`），一次性注册内容表后所有查表走同一入口。
- `engine/battle.ts` 加 `byId: Map<string, Unit>` 与 `_push(u)` 助手，**替换所有 `this.units.find(x => x.id === ...)` 为 O(1) `this.byId.get(id)`**；覆盖 5 处入列点（构造、`_push`、召唤、建筑/面包车、构造 spread）保证索引与数组一致。
- `rules/index.ts` 迁移 `HEROES.find` 到 `DB.get('heroes', id)`，清理未用 `HEROES` import。
- `src/backend/LocalBackend.ts` 暴露 `queryContent({table, where, opts})` —— **后端权威查表走同一 `DB` 抽象**，前后端同语义；`scripts/backend-poc.ts` 加 [6] 段实测（含 `$in` 多值查询）通过。
- 验证：`npm run backend` → ALL PASS（24）；`npm run parity` 校验和逐位一致；`npm run guard` 闸门通过。

## ② 手机端 PWA + 响应式
- **PWA**：`public/manifest.webmanifest`（standalone / 横屏 / 主题色 #14101a）+ `public/sw.js`（nav 走 network-first 回退缓存，asset 走 stale-while-revalidate）+ 180/192/512 三枚图标（深紫竞技场底 + 金色双环 + 三英雄辐条）。
- `index.html` 加 `theme-color` / `apple-mobile-web-app-capable` / `status-bar-style` / `apple-touch-icon` / `<link rel=manifest>`；`src/main.tsx` 仅在 `import.meta.env.PROD` 注册 SW（dev 模式 HMR 与 SW 不打架）。
- **Canvas 内部分辨率整数倍提升**：`ArenaCanvas` 加 `ResizeObserver` 观察容器，按 `Math.max(1, min(3, round(clientWidth/480)))` 计算 `scale`（封顶 3×），`canvas.width = 480*scale` + `ctx.setTransform(scale,0,0,scale,0,0)`，**drawFrame 仍按 480×312 逻辑坐标绘制**（已确认 frame.ts 不引用 canvas.width/height）—— 整数倍下 `pixelated` 零插值模糊，手机 2× DPR 屏清晰度直接翻倍。
- **触控回退**：`index.css` 加 `@media (hover: none) and (pointer: coarse)` 分支：按钮 `:active` 给 `scale(0.96)+brightness(1.15)` 按压反馈；全局 `touch-action: manipulation` 关双击缩放（消除移动端 300ms 延迟）；同时关掉触屏上的 `:hover` 残留态。
- **竖屏轻提示**：`<div id="rotate-hint">` 浮层（半透明胶囊 + 📱↻），**仅在触屏 + 竖屏时**显示，**不强制锁屏**（桌面端窄窗口不干扰），`pointer-events: none` 不抢焦点。
- 验证：`npm run build` → dist 包含 `sw.js` / `manifest.webmanifest` / 3 枚图标；`vite preview` 端到端：`/` / `/sw.js` / `/manifest.webmanifest` 均 HTTP 200。

## ③ 地图地块对齐需求
- 探索发现「**M 岩浆灼烧代码已写但地图未铺**」——3%/s 真伤逻辑（`battle.ts` 2611-2617）从未生效。`content/arenas.ts` 在 DRAGON / A3 布点 `M` 真铺出来。
- **新增三种地块效果**（`engine/battle.ts` 加 `_updateTileEffects()` 每 tick 钩子 + `Unit` 扩 `tileSpdMul`/`tileDmgTaken`/`tileRegenPct`）：
  - `w` 水域（可站立）→ 攻速 ×0.88（`attackInterval` 乘 `tileSpdMul`）
  - `P` 掩体 → 受到伤害 ×0.85（`applyDamage` 减伤后乘 `tileDmgTaken`）
  - `B` Boss 王座（仅 Boss 可踩）→ 受伤 ×0.80 + 每秒 2% 最大生命回血
- `content/arenas.ts` 在 RIVER/VAN 布 `w`、每关布 `P`、`BossLayer` 布 `B`；`Unit.isBoss` 标识直接用于王座判定。
- 实测脚本：站在 `M` 上的敌人 3 秒 HP 390→146（**灼烧贡献约 35 HP，其余为敌方普攻**）—— 证明两套系统同时跑通、战斗未崩、灼烧真在生效。
- 验证：`npm run smoke` / `integration` / `backend` 全绿；`npm run parity` 校验和逐位一致（说明改动确定性零回归）。

## ④ 角色/怪物风格化（纯渲染层）
- **Boss 王冠**：`frame.ts` 在 HUD 段按 `u.isBoss` 直接画金冠（双拱 + 中心宝石）—— 之前 Boss 视觉无差异化标识。
- **受击按伤害类型上色**：`Unit.flashType: 'physical'|'magic'|'hybrid'` 字段 + `applyDamage` 落地；flash 主色按类型（物理=暖白 255,228,180 / 魔法=冷蓝 180,210,255 / 混合=紫 220,180,255）—— 把"被打了一发火球/冰球/混合技"从纯白闪光升级为可读语义。
- **按职业 idle 振幅微调**：`IDLE_BOB_AMP: Partial<Record<SubClass, number>>` —— 9 职业各有不同呼吸幅度（重量型如重装减幅、轻灵型如刺客增幅），破除"全员同 bob"呆板感。
- 验证：`npm run typecheck` 零错误；所有测试套件仍全绿。
