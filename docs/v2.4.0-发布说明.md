# 无限勇者竞技场 · v2.4.0 发布说明

> **版本体系（v2.0.0 起 · 单一版本基线）**：本版本号 `2.4.0` 与 `package.json`、`CORE_VERSION`、git tag、压缩包名、线上 Pages 共用同一个号（末位恒为 0）。
> 本版本为**合并优化升级版**：以本地 `v2.3.0` 源码为基准，整合原由不可访问私有 dev 仓代构建的线上站点部署能力，并对线上部署形态做优化。`packages/core` 引擎**零改动**，确定性逐 bit 一致，回放契约兼容 `2.2.0`（旧 replay / 存档可复用，无需清库或强制刷新）。

## 二、特性清单

### ① 合并：GitHub Pages 自部署能力并回本地仓
- 原线上站点 `infinite-arena` 由**不可访问的私有 dev 仓** `infinite-arena-dev` 经 `deploy.yml` 自动构建并推送；本地仓（`infinite-arena-local`）仅有 `ci.yml` + `android.yml`，无法自部署。
- 新增 `.github/workflows/deploy.yml`：把 dev 仓的静态页面发布能力合并回本地仓。触发 `push → master` 或 `workflow_dispatch`，跑前置闸门（typecheck → guard → smoke → integration）→ 以子路径构建（`BASE_PATH=/仓库名/`）→ 经 `actions/deploy-pages` 发布到本仓 GitHub Pages。
- **base 路径按仓库名自动推导**（`/仓库名/`），不硬编码，适配任意仓库名；同时兼容 `GITHUB_PAGES=true → /infinite-arena/` 兜底。

### ② 优化：线上部署形态升级（代码分包 + 预压缩）
- 线上站点原先为**非分包单 bundle** 旧式构建（`main-*.js` 单文件），首屏需整包下载。
- 本版以本地源码构建上线：沿用 `vite.config.ts` 的 `manualChunks` 分包（`vendor-react` / `core` / `vendor` 独立长缓存块 + 各屏 `React.lazy` 懒加载块）+ `vite-plugin-compression2` 预生成 `brotli` / `gzip` 资产。
- 首屏仅拉 `main` + 前置 `vendor-react/core`，其余屏按需加载；关键 chunk 体积与首屏传输量下降，重复访问命中率提升。

### ③ core 引擎冻结（parity-safe）
- `packages/core` 零改动，`CORE_VERSION` 保持 `2.2.0`，确定性逐 bit 一致；旧 replay / 存档可复用，无破坏性变更。
- 遵循 v2.3.0 版本模型：引擎未变则仅升发布号（`package.json`），`CORE_VERSION` 冻结。
